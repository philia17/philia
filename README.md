# philia

a personal journal of languages, books, and music.

website: https://philia17.github.io/philia/

this independent arts website is published with github pages from the `main` branch. all public text stays lowercase. original photography credits, fan interpretation notes, poster downloads and font licenses remain with their assets. gaegu is distributed under its included open font license; third-party mv imagery and album artwork retain their owners' rights.

this publishing copy uses `/philia/` for navigation and assets. retain that prefix when updating it. `.nojekyll` serves the static html, svg, json, audio, images and fonts directly. do not upload private generator scripts or credentials.
